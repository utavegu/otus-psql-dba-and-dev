# Настройка PostgreSQL

В рамках этой домашней работы, помимо выполнения задания, я решил заодно и более глубоко разобрать некоторые темы. Каждый разбор сохранил в отдельной инструкции:

- [report.md](./report.md) - отчёт по домашнему заданию.

- [pgAdmin.md](./pgAdmin.md) - установка и настройка pgAdmin для подключения к серверу PostgreSQL, запущенному на виртуальной машине (для выполнения этого и последующих домашних заданий).

- [postgresql.conf.md](./postgresql.conf.md) - базовая инструкция по работе с postgresql.conf и postgresql.auto.conf.

- [pg_settings.md](./pg_settings.md) - базовая инструкция по работе с pg_settings.

- [pg_file_settings.md](./pg_file_settings.md) - базовая инструкция по работе с pg_file_settings.

- [pg_hba.conf.md](./pg_hba.conf.md) - базовая инструкция по работе с pg_hba.conf.

- [pg_ident.conf.md](./pg_ident.conf.md) - базовая инструкция по работе с pg_ident.conf.
